# E-Commerce Learning Project

A simple full-stack e-commerce application built primarily to learn and practice **Spring Boot API development** and understand how a backend interacts with a frontend and SQL database.

## Overview

This project implements a basic e-commerce workflow where users can:

* Register and log in
* View products
* Add products to their cart
* Checkout their cart

The project is intentionally simple and was built as a learning project to understand core Spring Boot concepts and REST API development.

## Tech Stack

### Backend

* Java
* Spring Boot
* REST APIs

### Frontend

* React

### Database

* SQL

## Features

* User registration
* User login
* Product listing
* Add products to cart
* View cart
* Checkout

## Project Structure

```text
project/
├── backend/       # Spring Boot application
└── frontend/      # React application
```

## Purpose

The main goal of this project is **learning**, rather than building a production-ready e-commerce platform.

It was created to practice:

* Building REST APIs with Spring Boot
* Connecting Spring Boot with a SQL database
* Handling CRUD operations
* Working with request/response data
* Connecting a React frontend with a Spring Boot backend
* Understanding the basic flow of a full-stack application

## Status

This is a learning project and may be extended with additional features as I continue learning Spring Boot and backend development.
